# My Express Auth App

[![Node.js](https://img.shields.io/badge/Node.js-v18.16.0-green)](https://nodejs.org/) 
[![Express](https://img.shields.io/badge/Express-v4.18.2-blue)](https://expressjs.com/) 
[![Passport](https://img.shields.io/badge/Passport-v0.6.0-lightgrey)](http://www.passportjs.org/)

A simple **Node.js Express application** with **user authentication** using Passport.js, session management, and MongoDB integration. Designed for learning purposes, prototypes, or small projects.

---

## Features

- ✅ User authentication with Passport.js  
- ✅ Session management using `express-session`  
- ✅ EJS templating engine for dynamic pages  
- ✅ Organized MVC structure (`routes`, `views`, `public`)  
- ✅ Error handling (404 and global errors)  
- ✅ Ready for cloud deployment (Render, Heroku, etc.)
